# セキュリティポリシー / Security Policy

## 脆弱性の報告 / Reporting a vulnerability

**公開のIssueには書かないでください。** GitHubの「Security」タブ →「Report a vulnerability」
（Private vulnerability reporting）から、非公開で報告してください。

Please do **not** open a public issue. Use the repository's **Security → Report a vulnerability**
(private vulnerability reporting).

- 対象は最新のリリースです。/ Only the latest release is supported.
- 個人開発のため、対応は可能な範囲での best effort です。/ This is a personal project; responses are best-effort.

## データの扱い / Data handling
外部に送信される情報の範囲は [PRIVACY.md](PRIVACY.md) を参照してください。
See [PRIVACY.md](PRIVACY.md) for what data leaves the browser.
