# 動作確認チェックリスト（実機・実サーバー）

これまでのテストは jsdom と偽fetch だけで、**実際のブラウザ・PubChem・Wikidata では一度も確認していません**（作業用の環境からは届かないため）。
このリストを、手元のFirefox（公開版、または `dist/firefox`）とChromeで実行し、結果を書き込んでください。
書き終えたら `HANDOFF.md` の 3-3 を更新します。

- 結果の記入: ✅ 期待どおり / ❌ 違った（内容をメモ）/ ➖ 対象外
- 期待値は2026年時点のPubChemでの値です。PubChem側の表記が変わっている可能性があるため、**少し違っても即不具合とは限りません**。違いを書き留めてください
- 失敗の調査には、拡張機能のポップアップを右クリック →「要素を調査」→ コンソール（Firefoxは `about:debugging` の「調査」から）を使います

## 準備
1. 読み込み
   - Firefox（公開版を入れるか、`about:debugging#/runtime/this-firefox` →「一時的なアドオンを読み込む」→ `dist/firefox/manifest.json`）
   - Chrome（`chrome://extensions` → デベロッパーモードON →「パッケージ化されていない拡張機能を読み込む」→ `dist/chrome`）
2. ツールバーにアイコンを固定する
3. バージョンを確認する（拡張機能の管理画面で 0.3.0）
